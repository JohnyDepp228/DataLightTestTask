# 3D-Визуализация данных VR-трекинга

Интерактивное графическое приложение на **C++ / Qt 5**, разработанное для покадрового анализа и 3D-воспроизведения движений человека на основе файлов трекинга устройств XR-Robotics.

---

## Выбранный подход и инструменты

В качестве основного инструмента был выбран стек **C++ и фреймворк Qt 5** (сборщик CMake, библиотека **Qt Data Visualization**).

* **Парсинг:** На основе структуры оригинального логгера (`SensorDataSaver`) был разработан зеркальный класс-парсер `SensorDataReader`. Он выполняет быстрое построчное чтение NDJSON-файла трекинга в оперативно создаваемые массивы структур данных.
* **Визуализация:** Для вывода точек в 3D используется класс `Q3DScatter`. Сцена настроена в контрастных темных тонах (`ThemeEbony`), а суставы отображаются в виде увеличенных ярко-красных 3D-сфер, что делает трекинг наглядным.
* **Воспроизведение:** В систему интегрирован автоматический таймер (`QTimer`), работающий с частотой ~20 кадров в секунду (15 мс). Это превратило приложение в полноценный 3D-плеер, циклично воспроизводящий трекинг движения в реальном времени.

## Возникшие сложности

1. **Проблема извлечения данных из файла:**
   При первоначальном просмотре файла было тяжело решить как удобнее и быстрее извлечь данные в нужном порядке и в нужные места.
   *Решение:* Был просмотрен предоставленный репозиторий что привело в оригинальной функции записи данных что в последствии и привело к решению проблемы с чтением данных.

## Инструкция по запуску


```
cd "имя папки куда будет клонирован репозиторий"

git clone https://github.com/JohnyDepp228/DataLightTestTask.git

mkdir ./build

cd build

cmake --build .

cmake ..

```
### Другой способ
1. Склонируйте репозиторий и откройте файл `CMakeLists.txt` в среде **Qt Creator**.
2. В файле `mainwindow.cpp` укажите актуальный абсолютный путь к вашему файлу данных `trackingData_20260505_165740.txt`.
3. Соберите и запустите проект (`Ctrl + R`).
4. Для вращения камеры зажмите **правую кнопку мыши** и перемещайте курсор. Для приближения/удаления используйте **колесико мыши**.
